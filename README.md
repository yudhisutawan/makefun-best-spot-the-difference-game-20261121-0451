Dua gambar nyaris sama, sepuluh perbedaan tersembunyi — temukan semuanya sebelum waktu habis! Game spot-the-difference orisinal yang berjalan offline di browser desktop dari file statis, tanpa network request.

## Cara main

- **Klik** perbedaan di gambar mana pun (kiri atau kanan) — lingkaran hijau menandai temuanmu.
- **3 level**: Pasar Senja, Taman Bunga, Pelabuhan Pagi — masing-masing 10 perbedaan.
- **3 kesulitan**: Santai (240 dtk), Normal (180 dtk), Cepat (120 dtk).
- **H** petunjuk (terbatas), **P** jeda, **M** suara, **R** ulang level.
- Klik salah mengurangi skor; selesaikan level tepat waktu untuk bonus.

## Teknologi

- Canvas 2D prosedural — semua gambar digambar dengan kode, tanpa aset eksternal.
- Suara WebAudio (oscillator) — tanpa file audio.
- Node 22 + browser desktop. Jalankan `node serve.ts`, buka http://localhost:8080.
